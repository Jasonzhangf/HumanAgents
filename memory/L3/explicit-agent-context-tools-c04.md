# C04 · 项目变更自动投递收件箱

项目模块负责查询、创建、修改、删除和成员配置。项目变更成功提交后，系统把变更事件自动投递到相关用户各自的收件箱，并按紧急程度自动选择打断通知或延迟通知。两种通知均保留收件记录，提交失败不发布成功变更事件。
