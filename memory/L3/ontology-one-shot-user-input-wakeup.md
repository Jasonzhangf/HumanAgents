# Ontology: One-shot user-input waiting and three-check resume

When a one-shot Task waits for user input, a user reply resumes it immediately. If three progress checks pass without a reply, the Task resumes using the accepted Goal and rules, records its automatic decision, and notifies the user Inbox without fabricating a user answer.
