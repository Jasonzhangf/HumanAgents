# 巡检提醒最后十次触发续订请求

用户确认：有限次巡检进入最后十次提醒时，每次实际发出提醒都携带续订请求。Agent 根据实际需求决定是否续订。续订只更新原订阅的剩余提醒次数。未续订时，提醒批次到期后停止发送提醒。巡检任务执行本身不受提醒停止影响；提醒只负责唤醒，不拥有巡检任务的生命周期。
