# Ontology: MVP delivery requires real frontend user-perspective acceptance

Before claiming MVP integration or completion, a tester must execute and pass all user-perspective tests on the real frontend and record reproducible evidence. Unit tests, builds, CI, or code reviews do not substitute for this gate.
