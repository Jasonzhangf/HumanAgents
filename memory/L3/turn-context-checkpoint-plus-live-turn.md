# Ontology: Per-turn context is Checkpoints plus live incomplete Turn, converging to Checkpoint plus timeline input

During reasoning, each session turn's active context consists of prior Checkpoints plus the current incomplete full Turn (all tool calls and results in this turn). Once the turn finishes, it converges into a Checkpoint plus user timeline input for subsequent turns.
