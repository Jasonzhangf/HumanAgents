# Ontology: Single-turn Checkpoint summary/detail split with simple-QA fast path

Each Checkpoint summarizes a single turn only. Complex turns must split into a short summary (stored in Checkpoint) and expandable detail (stored in expandable history that the model can open on demand). The closure gate must provide a simple-QA option that merges directly as a lightweight Checkpoint without requiring full structured forms.
