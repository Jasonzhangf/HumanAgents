# C03 · 框架按身份、operator 和配置执行

框架只看调用身份、目标 operator 和声明配置。根据配置核对该身份执行此 operator 的权限。权限不足时直接拒绝并返回错误，operator 不执行。权限满足时按配置调用 operator，由 operator 处理业务规则。
