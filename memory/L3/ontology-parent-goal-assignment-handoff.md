# Ontology: Parent orchestrator reassesses outstanding assignments on Goal change

When an accepted parent Goal changes, the current parent-task orchestrator assesses outstanding assignments against the revised Goal and updates or withdraws affected work. Transfer of parent-task responsibility transfers this duty to the successor.
