# C07 · 结束工具、格式纠错与 partial 续跑

结束当前推理 turn 时必须调用结束工具。简单任务选择「简单任务」并填写用户回复。复杂任务须提交用户回复及标准结束结构：总结段落、当前目标、过程、发现、建议的下一步；长篇细节落盘并在正文引用。格式有效后框架才接受正常收拢。格式无效时，工具把具体校验错误返回给 Agent；本轮前两次错误后继续推理、修正并再次调用。若同一轮第 3 次填写仍错误，框架以 partial 结束本次尝试，向用户报告可确认的进展和结束工具错误，并提供「继续」。用户选择继续时接续原交互或任务，保留可用进度和最近有效 checkpoint。无效调用不推进 checkpoint。正常收拢时 UI 展示用户回复，框架处理 capsule；有效探索进入主路径和下一推理轮，失败探索标明探索起点与错误记忆，从上一有效 checkpoint 带着该记忆继续推理。
