# Ontology: Defer Task success when prior unknown Operation affects current Goal acceptance

Once the user confirms a Goal change, available results may be shown immediately, but if a previously started Operation has an unknown result affecting current Goal acceptance, the Task must report the uncertainty, retain reconciliation responsibility, and defer committing Task success until the result is known and assessed.
