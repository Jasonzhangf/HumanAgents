# 显式 Agent 管理职责、角色模板与基础通信顺序

用户已确认设计并授权基础实现。显式 Agent 是对内对外的请求接口，负责理解、分派、跟踪并向原请求人交付。通用模板负责持续运行、资源回收和消融；CEO 对跨项目目标负责，项目负责人对项目交付负责。两类管理者分别加载自己的角色提示，明确唯一最终负责人、标准任务派发、按依赖并发、返回结果验收与返工、困难恢复和升级、空循环反思及无行动时取消订阅并保留恢复信号。框架工具和真实回执决定是否已执行管理动作。先验证单 Agent 的复杂任务 bash、正常收拢 checkpoint 和新 turn，随后优先把基础通信接入内置工具和内置提示，沿既有寻址、权限及消息队列完成真实投递与回执。每次 call 的 usage、缓存率、速度和 context 实际占用由非 UI 接口提供给 UI，未知值不能视为零。此条记录目标与优先级，行为状态见逐调用统计与真实联调合同.md。
