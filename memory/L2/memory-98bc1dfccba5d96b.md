# Ontology: Explicit Brain vs Implicit Brain responsibility boundary

Explicit Brain answers simple questions directly and decomposes complex goals into FIFO RequirementEnvelopes for Implicit Brain without executing tasks itself. During execution, Explicit Brain relays user questions and returns answers to resume the same Task. Control commands (steer/stop/revoke) never enter the business requirement queue.
