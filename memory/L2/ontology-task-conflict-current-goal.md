# Ontology: Resolve Task conflicts by latest requirements or default path with reminder

All Tasks follow the latest confirmed requirements when resolving conflicts. An executor may ask the user when unsure; absent a ruling, it follows the applicable default path and records the decision in the user's to-do reminders.
