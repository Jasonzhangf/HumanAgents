# Ontology: Task is a trigger-driven business work object

Task is a user-visible business work object with exactly two top-level kinds (one-shot, periodic) and four main states (created, active, waiting, closed). Triggers enter a unified SESE intake/update path; subagent explorations stay Assignment/PlanStep/Cycle/Operation inside parent Task.
