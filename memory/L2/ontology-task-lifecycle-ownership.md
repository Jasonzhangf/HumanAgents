# Ontology: Task owns main lifecycle states; execution records own execution facts

Task owns only the four main states (created, active, waiting, closed) and its closed outcome. Task-scoped Cycle, Operation, and Checkpoint records own their execution facts and outcomes without overwriting Task main state. Taskless interaction stays on InteractionClosure without Task, Cycle, Operation, or Checkpoint identity.
