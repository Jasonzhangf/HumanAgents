# Ontology: Goal change immediately updates GoalRevision and continues same Task

When the user changes the Goal during execution, the Task immediately enters the Goal-change flow and the current Cycle stops advancing the old Goal. After clarifying and committing the updated GoalRevision, the Task evaluates existing results against the updated Goal, updates its plan, and continues on the same Task.
