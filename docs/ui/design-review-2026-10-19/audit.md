# 静态设计审计

## 本轮范围

本目录是使用示例数据的静态设计稿，不连接真实 Provider、运行时或任务数据。本轮只修改 `index.html` 与 `audit.md`。未改产品代码、需求、图、配置、安装、运行状态或网络资源。

## 已实现静态行为

- 左侧只保留五个同级板块：交互 agent、编排 agent、巡检 agent、执行 agent、记忆 agent。当前板块高亮，旧桌面和手机项目树已物理移除。
- 五个入口改为紧凑卡片，展示各自当前任务名与现有状态。桌面和手机复用同一渲染与状态来源；板块标题进入 dashboard，任务行进入对应 session，各链接同级、不嵌套。历史不进入卡片。执行 agent 原周报任务随现有工具条状态同步，已有成果不显示为执行中。
- 卡片支持多条 Live 任务，执行 agent 下放置三条独立任务，左侧与中心列表共用同一集合。板块标题和各任务为同级链接，分别进入 dashboard 与对应 session；当前板块和当前任务分别高亮。新增任务不接入无依据的关联链，状态不受原周报任务的工具条控制。
- 各板块 dashboard 显示实时与历史列表。进入 session 后不再堆放完整列表；项目、任务和实例信息位于所属板块及 session 中。
- 板块 dashboard 与选中 session 按路由分层。选中后，中间显示对应 agent 的需求、回复、编排或执行记录；巡检与记忆的常规流程不等待人工回复，但保留可选的人类介入入口。右侧显示当前 focus 所在的完整关联链，节点只出现一次并标明当前焦点，点击节点同步切换中间 session。当前链与历史链不混合，也不为巡检和记忆编造关联。
- 沿用 hash、pushState 和 popstate。路由同时携带板块、实时或历史、实体标识；刷新与深链恢复同一选择。
- 选择实体后中心保留 session 正文，右侧只展示关联链，所有 focus 均不重复中心内容。有已知关联才自动打开右侧，无关联不自动展开空面板。三项产品实体关系为：交互需求到编排的“投递需求”、编排到执行的“编排任务”、历史编排到历史执行的“当时编排”。巡检和记忆没有虚构关系，也不展示空关联说明。
- 导航不改变示例任务状态。只有设计工具条和审批动作可以改变任务示例状态。等待任务首次被选择时打开审批；关闭、外部点击和 Escape 只关闭展示，并返回有效入口焦点。
- 历史记录不显示当前批准、输入或状态变化。等待和终止记录不显示已读取、步骤、进度或结果。无效成果深链会归一化，不伪造完成状态。
- 桌面中心工作区可滚动，选中 Live session 的底部保留人类输入框。手机导航和细节共用一个底部抽屉，外部点击关闭且不穿透。
- 所有选中 Live session 保留人类介入输入，标明人类身份和最高控制权限。交互 agent 为日常人类对话入口；其余适用 session 的普通来源标明“编排 agent · 任务安排”，仅表示接口角色，不捏造具体编排实例或关联边。普通流程不依赖人类回复。示例发送只在对应 session 显示人类指令，不生成普通 agent 回复，不改变任务状态或自动批准。历史归档保持只读。

## 复用基线

边框配置入口、桌面辅助区折叠、焦点恢复和既有桌面与手机布局沿用原设计。负责人已另行在浏览器走通本轮五板块的实时/历史、交互→编排→执行、保持等待、层级返回/浏览器后退、历史编排→历史执行及刷新恢复。真实 390 宽度下的单抽屉导航、关联跨板块和关闭均已操作，无横向溢出。

前次五板块基线记录为 `navigation-semantics-20261019/root-static-board-acceptance.md`，截图为 `five-agent-desktop.png` 与 `five-agent-mobile.png`。本轮卡片、session 与整链的实际浏览器证据为同目录 `root-focus-chain-acceptance.md`，最终桌面截图为 `focus-chain-desktop.png`。

本轮已核对卡片状态同步、session 不堆 dashboard、实时整链去重与跨 focus 跳转、历史链独立、巡检无输入，以及真实 390 宽度下的手机卡片、单抽屉和历史 focus 切换，无横向溢出。执行 focus 右侧只保留链路、巡检不自动打开空面板，两项也经刷新确认。仅顶部设计工具条标明示例，不在产品主区重复说明。

多 Live 修订已另经浏览器确认：桌面三项各自进入 session，板块 dashboard 与卡片展示同一集合，原周报状态切换不改变新增任务状态；手机从导航抽屉点任务后先关闭抽屉，再显示 session，焦点返回入口，390 宽度无横向溢出。从关联抽屉点击链路则保留关联并切换 focus。记录为同目录 `root-multi-live-acceptance.md`，截图为 `multi-live-desktop.png` 与 `multi-live-mobile.png`。

人类介入修订也已实际操作：原待批任务保持等待；向巡检发送只新增人类消息，不伪造 agent 回复或改变状态；切换记忆 session 没有串消息。普通来源与人类控制身份清楚分开，交互 agent 显示日常人类对话，历史归档只读。真实 390 宽度下输入可见，无横向溢出。记录为同目录 `root-human-command-acceptance.md`，截图为 `human-command-desktop.png` 与 `human-command-mobile.png`。
