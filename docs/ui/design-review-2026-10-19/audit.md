# 静态设计审计

本目录是使用示例数据的可点击设计稿，不是已上线界面，不操作真实任务。

## 旧稿应保留

旧稿已有任务优先的内容顺序：标题、当前处理、已有结果，再按需查看过程和资料。桌面旁侧详情与手机底部抽屉也是已有正确设计。本稿沿用这些原则，补充项目与任务的辅助目录。

旧稿本轮通过源码和仓库已有预览图片核对，没有重新在浏览器渲染旧 HTML。

## 当前实测偏离

- 实际页面顶栏缺少清楚的当前位置和层级返回；所属项目链接丢失读取模式。
- 关闭授权弹窗后地址仍保留打开标记，浏览器后退会重新打开；点击外部空白不能关闭。原关闭按钮返回焦点已实测成功，不能把它写成缺陷。
- 页面存在同步成功、正常连接、读取完整等非必要说明，以及尚无结果时的空结果块。
- 首版新稿也有手机控件重叠、配置入口遮挡详情、审批未自动打开和导航误改示例任务状态的问题，需修订，不能据此否定旧稿整体。

## 新稿修订

- 边框仅保留轻量配置入口；辅助目录可折叠，中心显示任务主线，详情按需在右侧或手机底部打开。
- 等待批准时直接展示批准与拒绝；关闭只影响弹窗，保留等待并返回入口焦点。
- 浏览导航不推进任务。只有独立设计工具条和明确的审批演示动作切换示例状态；没有结果时不显示成果目录。
- 新建任务只收用户需求，不另收任务名称或类型。提交仅在本页演示。
- 收紧手机页头和审批摘要，输入位于主工作区底部。任务列表与新建属于同一任务区域。

## 未验证

本轮静态交互已在浏览器走通：审批自动打开、空白关闭、Escape、返回焦点、批准进入整理与拒绝停止；层级返回和浏览器后退不重开已关闭审批；目录可折叠，无成果时不显示成果项。手机导航与详情共用一个底部抽屉，点击外部只关闭抽屉、不穿透下层动作，任务保持等待并返回位置入口焦点。

已检查 1280×900、1265×710 桌面输入可见，以及 390×844 手机布局；桌面已加载后缩到 390 宽度会自动切换手机布局，无横向溢出。截图位于本轮记录目录 `navigation-semantics-20261019/design-desktop.png` 和 `design-mobile.png`。

这些证据仅证明静态示例的交互和排版。用户尚未审计同意，不代表真实任务或产品验收；没有执行真实任务、运行时接口或产品安装。

机械检查因本机解析依赖缺失而降级为文本检查，未测计算后对比度，不能据此声称完整无障碍检查通过；未安装依赖或增加门禁。
