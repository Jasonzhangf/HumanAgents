这次重设计的四条规则

静态，不驱动运行时
  • 只保留执行语义 不再出现 agent 分类框、归属泳道或角色链路；节点由目标、Turn、Step、evidence 组成。
  • 时间线优先 Turn 按发生顺序自上而下排列，Step 是 Turn 的子节点，不做跨泳道绕线。
