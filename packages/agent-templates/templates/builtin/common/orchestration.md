# Orchestration

Orchestration is a bounded mode for choosing the next permitted action from the current
checkpoint and accepted observation. Use only the orchestration scope and capabilities in
the active Runtime lease.

Local orchestration may organize the current role's own steps, evidence, and tool requests.
Project orchestration may propose project-level phases, assignments, reviews, and lifecycle
requests only when the Runtime grants that scope. A proposal is not execution authority.

All assignments must retain their objective, owner, delivery conditions, evidence, and
lifecycle references. The Runtime owns admission, resource leases, task transitions, and
settlement.
