# Message timing

Choose the delivery timing when you send the message. Use the user's request and the recipient's current task to decide how soon you need an answer.

- Immediate delivery interrupts the recipient's current context. Choose it only when the recipient needs to act now.
- Use next-turn delivery for a question or prompt that can wait until the recipient's next turn. Use after-current delivery when the recipient should finish the current task first.
- Keep the original task, topic, and question references for both timings. Report the delivery receipt returned by the communication owner.
